当点击表格中的虚拟机名字时，进入【虚拟机详情】页面，此页面的颜色与主页面一致，都是使用：background-color: #f8f9fa;，在此页面主要布局：
1）第一行有一个【返回列表】按钮
2）第二行第三行分别显示虚拟机【名称】【状态】【VCPUS】【内存】【描述】等信息，可以使用只有一行的表格实现。
3）接下来有8个子标签和对应的页面，分别是【电源】【控制台】【快照池】【统计】【设置】【迁移】【克隆】【销毁】，并有相应的图标。
4）当点击【电源】标签时，显示【启动】标签子页，此标签子页有启动说明文字和【开机】按钮；
5）当点击【控制台】标签时，显示【控制台】标签子页，此标签子页有下拉列表，分别vnc和spice两种可选项，并有相关的文字说明，还有一个按钮【设置控制台类型】。
6）当点击【快照池】标签时，显示【创建快照】和【从快照恢复】两个子标签页面，点击【创建快照】子标签时，显示创建快照的标签子页；点击【从快照恢复】子标签时，显示从快照恢复了标签子页，在此子页有相关的快照列表，有表格形式呈现。
7）当点击【统计】标签时，显示【CPU】【网卡】【内存】【硬盘】三个子标签和三个子页面。点击【CPU】子标签时，显示5分钟内的虚拟机CPU使用率子页面，并在二维的直角坐标序画出；点击【内存】子标签时，显示虚拟机内存在5分钟内的使用率子页面，并在二维的直角坐标序画出；
   点击【网卡】子标签时，显示虚拟机所有网卡的在5分钟内的速率子页面，并在二维的直角坐标序画出；点击【硬盘】子标签时，显示虚拟机所有可读写硬盘（如sda，vda）的读写速率子页面，并在二维的直角坐标序画出。
8）当点击【设置】标签时，显示【VCPU】【内存】【ISO】【网络】【硬盘】【XML】【内核日志】7个子标签和7个子页面，可以在6个子页面对【VCPU】【内存】【ISO】【网络】【硬盘】【XML】进入编辑保存，【内核日志】子页面显示的是操作系统的完整日志信息，与执行dmesg -T命令的结果一样。
9）当点击【迁移】标签时，显示虚拟机【迁移】子页面，在这子页面上有迁出的标地址和三个复选框：Live migration、Unsafe migration和Delete original，页面右下角有【迁移】按钮；
10）当点击【克隆】标签时，显示虚拟机【克隆】子页面。
11）当点击【销毁】标签时，显示【删除虚拟机】的子页面，在此子页面有“确定删除包括硬盘镜像虚拟机？”，页面右下角有【删除】按钮；
