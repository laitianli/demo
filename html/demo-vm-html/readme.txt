--主页面
当点击表格中的虚拟机名字时，进入【虚拟机详情】页面，此页面的颜色与主页面一致，都是使用：background-color: #f8f9fa;，在此页面主要布局：
1）第一行有一个【返回列表】按钮
2）第二行第三行分别显示虚拟机【名称】【状态】【VCPUS】【内存】【描述】等信息，可以使用只有一行的表格实现。
3）接下来有8个子标签和对应的页面，分别是【电源】【控制台】【快照池】【统计】【设置】【迁移】【克隆】【销毁】，并有相应的图标。
4）当点击【电源】标签时，显示【启动】标签子页，此标签子页有启动说明文字和【开机】按钮；
5）当点击【控制台】标签时，显示【控制台】标签子页，此标签子页有下拉列表，分别vnc和spice两种可选项，并有相关的文字说明，还有一个按钮【设置控制台类型】。
6）当点击【快照池】标签时，显示【创建快照】和【从快照恢复】两个子标签页面，点击【创建快照】子标签时，显示创建快照的标签子页；点击【从快照恢复】子标签时，显示从快照恢复了标签子页，在此子页有相关的快照列表，有表格形式呈现。
7）当点击【统计】标签时，显示【CPU】【网卡】【内存】【硬盘】三个子标签和三个子页面。点击【CPU】子标签时，显示5分钟内的虚拟机CPU使用率子页面，并在二维的直角坐标序画出；点击【内存】子标签时，显示虚拟机内存在5分钟内的使用率子页面，并在二维的直角坐标序画出；
   点击【网卡】子标签时，显示虚拟机所有网卡的在5分钟内的速率子页面，并在二维的直角坐标序画出；点击【硬盘】子标签时，显示虚拟机所有可读写硬盘（如sda，vda）的读写速率子页面，并在二维的直角坐标序画出。
8）当点击【设置】标签时，显示【VCPU】【内存】【ISO】【网络】【硬盘】【XML】【内核日志】7个子标签和7个子页面，可以在6个子页面对【VCPU】【内存】【ISO】【网络】【硬盘】【XML】进入编辑保存，【内核日志】子页面显示的是操作系统的完整日志信息，与执行dmesg -T命令的结果一样。
9）当点击【迁移】标签时，显示虚拟机【迁移】子页面，在这子页面上有迁出的标地址和三个复选框：Live migration、Unsafe migration和Delete original，页面右下角有【迁移】按钮；
10）当点击【克隆】标签时，显示虚拟机【克隆】子页面。
11）当点击【销毁】标签时，显示【删除虚拟机】的子页面，在此子页面有“确定删除包括硬盘镜像虚拟机？”，页面右下角有【删除】按钮；

--存储池
使用jQuery和bootstrap实现一个这样的存储池页面，其中图片是这个子页面的风格和布局，当点击左侧的【存储池】时，右侧区域切换到【存储池】子页面，在此子页面有如下html元素：
1）第一行右上角【新建立存储池】按钮；
2）接下来是四个Card组件（bootstrap组件），分别是：【本地存储池】【ISO池】【网络存储池】【CEPH存储池】，它们以2行2列进行布局；
3）在【本地存储池】Card组件显示标题、存储池目录下的虚拟机镜像文件占用物理磁盘空间使用量和虚拟机镜像文件的总个数。当点击标题时，打开一个【本地存储池】子页面，在子页面默认显示libvirt默认路径：/var/lib/libvirt/images存放虚拟机的硬盘文件，
   也可以自定义目录，并且可以添加多个自定义目录做为【本地存储池】目录。
   在子页面最后显示每个目录下有多少个虚拟机镜像文件和占用物理磁盘空间，并以目录为一个表格的形式呈现出来。表格有这些内容：ID、镜像文件名、镜像文件大小、格式、操作，在操作这一列有【克隆】【删除】两个按钮
4）在【ISO池】Card组件显示标题、存储池目录下的ISO文件占用物理磁盘空间使用量和ISO文件总个数。当点击标题时，打开一个【ISO池】子页面，显示ISO池的目录，占用物理硬盘空间大小，同时在有一个【上传ISO】按钮用于从windows传ISO文件到linux服务器上。
   下方有一个表格，表格有这些内容：ID、文件名、文件大小、格式、操作，在操作这一列有【删除】按钮。
5）在【网络存储池】Card组件显示标题、存储池目录下的虚拟机镜像文件占用物理磁盘空间使用量和虚拟机镜像文件的总个数。当点击标题时，打开一个【网络存储池】子页面，此子页面显示4个子标签，分别是：NFS、CIFS、ISCSI和Glusterfs。当点击这四个标签，就在子页面显示
   NFS文件系统的配置信息、CIFS文件系统配置信息、iscsi文件系统的配置信息、Glusterfs文件系统配置信息，在对应子页面下方以表格的形式显示，表格同样有这些内容：ID、镜像文件名、镜像文件大小、格式、操作，在操作这一列有【克隆】【删除】两个按钮。
6）在【CEPH存储池】Card组件显示标题、存储池目录下的虚拟机镜像文件占用物理磁盘空间使用量和虚拟机镜像文件的总个数。当点击标题时，打开一个【CEPH存储池】子页面，此子页面显示CEPH服务器的配置信息。

--网络池
使用jQuery和bootstrap实现一个这样的网络池页面，页面风格要与存储池页面一致，当点击左侧的【网络池】时，右侧区域切换到【网络池】子页面，在此子页面有如下html元素：
1）第一行右上角【新建立网络池】按钮；
2）接下来是四个Card组件（bootstrap组件），分别是：【NAT网络池】【Bridge网络池】【Host网络池】【OpenVSwitch池】，它们以2行2列进行布局；
3）在【NAT网络池】Card组件显示标题和子网信息，子网信息如：virbr0：192.168.122.0/24和virbr1：172.16.123.0/24，它们可以使用表格形式显示，最多显示5条，
   超出时就显示滚动条，其中virbr0和virbr1是网卡名，会在物理机上创建的网络接口；
   当点击标题时，打开一个【NAT网络池】子页面,在【NAT网络池】子页面分上下两区域：新建NAT网络池和NAT网络池列表。在新建NAT网络池区域：有可以输入的网卡名、子网信息、是否开启DHCP复选框和一个【新建】按钮；
   在NAT网络池列表区域：以表格的形式显示【新建】按钮的结果，此表格列名：ID、网卡名、子网信息、是否开启DHCP和操作，在操作列有【编辑】【删除】，点击【编辑】按钮时，表格中的子网信息和是否开启DHCP两单元格进入编辑模式，在【删除】按钮可以删除表格一整行；
4）在【Bridge网络池】Card组件显示标题和网桥信息，网桥信息如：bridge0: 00:10.ab:12:a1:2c和bridge1: 00:20.ab:12:a1:2c，它们可以使用表格形式显示，最多显示5条，
   超出时就显示滚动条，其中bridge0和bridge1是网桥名，会在物理机上创建的网络接口；
   当点击标题时，打开一个【Bridge网络池】子页面,在【Bridge网络池】子页面分上下两区域：新建Bridge网络池和Bridge网络池列表。在新建Bridge网络池区域：有可以输入的网桥名、MAC信息和一个【新建】按钮；
   在Bridge网络池列表区域：以表格的形式显示【新建】按钮的结果，此表格列名：ID、网桥名、MAC信息和操作，在操作列有【编辑】【删除】，点击【编辑】按钮时，表格行中的MAC地址单元格进入编辑模式，在【删除】按钮可以删除表格一整行；
5）在【Host网络池】Card组件显示标题和Host信息,Host信息如：enp3s0: 192.168.10.1 enp4s0:172.15.88.1，它们可以使用表格形式显示，最多显示5条，超出时就显示滚动条，
   其中enp3s0和enp4s0是物理机上的网卡名，后面是配置在物理网卡上的IP。
   当点击标题时，打开一个【Host网络池】子页面,在【Host网络池】子页面分上下两区域：新建Host网络池和Host网络池列表。在新建Host网络池区域：有可以选择物理网卡的下拉式列表框、IP地址信息和一个【新建】按钮；
   在Host网络池列表区域：以表格的形式显示【新建】按钮的结果，此表格列名：ID、物理网卡名、IP信息和操作，在操作列有【编辑】【删除】，点击【编辑】按钮时，表示的IP信息单元格进入编辑模式，在【删除】按钮可以删除表格一整行；
   在新建完一个Host池后，物理网卡要从下拉式列表框中删除，相反，当【删除】一个表格行时，要把相关的物理网卡插入到下拉式列表框中。
6）在【OpenVSwitch池】Card组件显示标题和OpenVSwitch信息，其中OpenVSwitch信息如：ovs0: 10:10.ab:12:a1:2c和ovs1: 10:20.ab:12:a1:2c，它们可以使用表格形式显示，
   最多显示5条，超出时就显示滚动条，其中ovs0和ovs1是网桥名，会在物理机上创建的网络接口；
   当点击标题时，打开一个【OpenVSwitch网络池】子页面,在【OpenVSwitch网络池】子页面分上下两区域：新建OpenVSwitch网络池和OpenVSwitch网络池列表。在新建OpenVSwitch网络池区域：有可以输入的ovs网桥名、MAC信息、是否启用DPDK选择框和一个【新建】按钮；
   在OpenVSwitch网络池列表区域：以表格的形式显示【新建】按钮的结果，此表格列名：ID、OpenVSwitch网桥名、MAC信息和操作，在操作列有【编辑】【删除】，点击【编辑】按钮时，表格行中的MAC信息和是否启用DPDK两单元格进入编辑模式，在【删除】按钮可以删除表格一整行；
